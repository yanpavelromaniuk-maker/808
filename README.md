# Ян. ML × VET

Портфолио CV/ML инженера и ветеринарного врача КРС. Статический сайт без сборки: чистый HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` напрямую или поднимите локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`. Страница 404 доступна по адресу `http://localhost:8080/404.html`; на хостинге с поддержкой `404.html` она покажется автоматически.

## Что заменить перед публикацией

1. **Контакты.** Сейчас в проекте стоят аккуратные плейсхолдеры. Замените:
   - `hello@yanvet.pro` на реальную почту (в ссылках `mailto:`, тексте, `data-copy`, футере и мобильном меню);
   - `https://t.me/yanvet` и `@yanvet` на Telegram;
   - `https://www.linkedin.com/in/yanvet/` и `in/yanvet` на LinkedIn.
2. **Визуал в hero.** В `index.html` найдите `data-placeholder-img`. Замените прозрачный `src` на путь к своему PNG, например `images/cow.png`, и заполните `alt`. Контейнер уже держит сетку и пропорции. Сейчас на главной намеренно оставлен пустой слот под будущий визуал; все изображения для 404 уже подключены.
3. **OG-обложка.** `images/og-cover.jpg` — социальная обложка 1200 × 630, сделанная из реального рендера сайта. При желании замените её своей.
4. **Домен и canonical.** Если появится домен, добавьте canonical и при необходимости `hreflang`; сейчас их нет, чтобы не публиковать вымышленный URL.

## Структура

```text
index.html          Главная
404.html            Брендированная страница ошибки
style.css           Дизайн-система, сетка, адаптив, motion
script.js           Lenis, reveal, параллакс, язык, меню, копирование email
fonts/              Unbounded и Manrope, скачанные из Google Fonts
vendor/             Lenis и MIT-лицензия
images/             Исходные изображения и оптимизированные WebP
screenshots/        Проверка вёрстки в headless Edge
```

## Проверка вёрстки

Финальные скриншоты сняты в headless Edge:

- `screenshots/yan-home-desktop.png` — главная, 1440 × 900;
- `screenshots/yan-home-mobile.png` — главная, 390 × 844;
- `screenshots/yan-mobile-menu.png` — мобильное меню;
- `screenshots/yan-404-desktop.png` — 404, 1440 × 900;
- `screenshots/yan-404-mobile.png` — 404, 390 × 844.

Проверены ширины от 320 до 1920 px: горизонтального скролла нет. Переключение RU / EN, меню с focus trap, копирование email, reduced motion и появление секций по IntersectionObserver проверены в браузере.

## Технические детали

- Heading font: **Unbounded** weights 500–600. Text font: **Manrope** 400–600. Оба шрифта загружены из Google Fonts и подключены локально; лицензии OFL лежат в `fonts/`.
- Motion: Lenis, IntersectionObserver, пословное появление манифеста, лёгкий параллакс, магнитные состояния через CSS и hover-свечения. Всё отключается при `prefers-reduced-motion: reduce`.
- Переключатель RU / EN сохраняет язык в `localStorage`; переводится весь контент, включая метаданные и страницу 404.
- Внешних аналитических скриптов, форм и cookie-трекеров нет.
- Изображения для 404 отдаются как WebP с fallback на исходные PNG/JPG. Оригиналы не изменены.
- Контактные ссылки — плейсхолдеры до замены; формы обратной связи нет, поэтому сообщения не теряются на стороне сайта.
